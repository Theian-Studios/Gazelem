Proof Techniques Review: Sections 6–11

Based on A Transition to Advanced Mathematics (Doud & Nielsen) for BYU Math 290.

Convention: \(\mathbb{N}=\{1,2,3,\dots\}\)

Overview

Sections 6–11 are about how to write a proof. Almost every statement you'll prove is a “for all” implication (\(\forall x,\ P(x)\Rightarrow Q(x)\)), a set relationship, or a “there exists” claim. Each section adds one tool:

§ToolIdea in one lineSignal
6Direct proofAssume \(P\), show \(Q\).The premise is easy to unpack.
7ContrapositiveAssume “not \(Q\),” show “not \(P\).”The conclusion's negation is easier to use.
8CasesSplit into possibilities that cover everything.Even/odd, remainders mod \(n\), absolute values, “or.”
9ContradictionAssume the claim is false; reach something impossible.“Irrational,” “no…,” “\(\ne\),” “does not divide.”
10Set proofsTake an arbitrary element and chase it.\(\in\), \(\subseteq\), \(=\) between sets.
11Existence / counterexampleOne example proves “there exists” or kills a “for all.”“There exists,” “prove or disprove,” “unique.”

How to use this page: skim the tables in this top half first, read Common mistakes before a quiz, and use the section summaries and flashcards to check yourself. The filter box on the left narrows everything to a keyword.

A workflow for any proof

1. Rewrite the claim in logic: what are the quantifiers, the premise, the conclusion? 2. Decide if it's true (try small examples). If false, find a counterexample. 3. Pick a technique (table below) and say it: “We work directly / contrapositively / by contradiction.” 4. Unpack every definition (even, odd, divides, congruent, \(\in\)) into an equation with a new letter. 5. Don't solve for a variable by dividing (the result may not be an integer). Rearrange and factor toward the form the definition needs: \(2(\cdot)\), \(2(\cdot)+1\), \(n(\cdot)\). 6. Conclude by naming why: “Since \(2k^2+1\in\mathbb{Z}\), \(n^2-2n+3=2(2k^2+1)\) is even.” \(\square\)

Facts you can use & classic counterexamples

Facts you can cite (results, examples & exercises) Parity & divisibility
Every integer is even or odd, never both (axiom, §6.A).
\(n^2\) odd \(\iff n\) odd (Prop 7.16).
\(3\mid n\iff 3\mid n^2\) (Exercise 8.5) — the key lemma for \(\sqrt3\).
\(a\mid b,\ b\mid c\Rightarrow a\mid c\) (Prop 7.13).
\(a\mid b,\ a\mid c\Rightarrow a\mid(bx+cy)\) (Thm 7.15).
Congruence mod \(n\)
Every integer is exactly one of \(3k,3k+1,3k+2\) (Example 8.14).
\(a\equiv b\Rightarrow ac\equiv bc\) (Prop 8.13).
\(a\equiv b,\ b\equiv c\Rightarrow a\equiv c\) (Exercise 8.4).
\(a\equiv b,\ c\equiv d\Rightarrow ac\equiv bd\) (Exercise 8.7).
Squares are \(\equiv0\) or \(1\pmod4\) (Exercise 8.3).
Real numbers
\(ab=0\iff a=0\) or \(b=0\) (Thm 8.9).
\(|x+y|\le|x|+|y|\) (Thm 8.21) and \(|xy|=|x||y|\) (Thm 8.22).
Rational \(+\) irrational is irrational; nonzero rational \(\times\) irrational is irrational (Exercises 9.6–9.7).
Classic counterexamples \(a\mid b\) and \(b\mid a\) but \(a\ne b\): \(a=2,b=-2\).
\(a\mid2b\) but \(a\nmid b\): \(a=2,b=1\).
\(a^2\mid b^3\) but \(a\nmid b\): \(a=8,b=4\).
\(a\nmid b\), \(a\nmid c\), but \(a\mid bc\): \(a=4,b=c=2\).
Rational \(\times\) irrational rational: \(0\cdot\sqrt2\).
\(A\cup C\subseteq B\cup C\) but \(A\not\subseteq B\): \(A=C=\{1\},B=\varnothing\).
\(x>\tfrac12x^2\) fails at \(x=0\).

Common mistakes

The errors graders see most, grouped by type. Each has the fix.

If you only remember five 1. Examples prove “there exists,” never “for all.”
2. New letter for every new number: \(x=2k,\ y=2\ell\).
3. Don't divide to solve for an integer — rearrange and factor.
4. Contrapositive assumes the negated conclusion; “not (A and B)” is “not A or not B.”
5. Cases must cover everything; sets need both inclusions.

Setting up the proof

  • ✗ Proving a “for all” statement by checking one or a few examples. ✓ Start with “Let \(x\in S\)” (arbitrary). Examples only prove “there exists.” (§11)
  • ✗ Reusing one letter: “\(x,y\) even, so \(x=2k,\ y=2k\).” ✓ \(x=2k,\ y=2\ell\). One letter forces \(x=y\). (see the Question after Prop 7.13)
  • ✗ Not saying which method you're using. ✓ “We work directly / contrapositively / by contradiction.” For prove-or-disprove, open with “Proof.” or “Disproof.” (Advice 11.13)
  • ✗ Ending on an expression without saying why it qualifies. ✓ “Since \(2k^2+1\in\mathbb{Z}\), \(n^2-2n+3\) is even.”
  • ✗ Using “trivial” to mean “easy, so I'll skip it.” ✓ Trivial means the conclusion is always true — still show why. (Warning 6.8)

Logic

  • ✗ Proving the converse by accident: to show “if \(2\mid x\), then \(x\) even,” assuming \(x\) even and showing \(2\mid x\). ✓ Contrapositive assumes the negated conclusion. (Exercise 7.4)
  • ✗ Negating “and” as “and”: not(\(x\) odd and \(y\) even) ≠ “\(x\) even and \(y\) odd.” ✓ It's “\(x\) even or \(y\) odd” — usually two cases.
  • ✗ Proving only one direction of an “if and only if.” ✓ Two labeled parts, \((\Rightarrow)\) and \((\Leftarrow)\).
  • ✗ Reading “\(P\) only if \(Q\)” as \(Q\Rightarrow P\). ✓ It's \(P\Rightarrow Q\): “\(5x-1\) is even only if \(x\) is odd” means “if \(5x-1\) is even, then \(x\) is odd.” (Exercise 7.8)

Algebra with integers

  • ✗ Dividing: \(3n=2k\Rightarrow n=\tfrac{2k}{3}\), or \(2b=ac\Rightarrow b=a\cdot\tfrac c2\). The fraction may not be an integer (and “\(a\mid2b\Rightarrow a\mid b\)” is false). ✓ Rearrange and factor instead: \(n+7=3n-2n+7=2k-2n+7=2(k-n+3)+1\). (Prop 6.19; Prop 7.12, labeled “False!”)
  • ✗ Treating \(a\mid b\) as the number \(a\div b\). ✓ It's the sentence “\(b=ac\) for some \(c\in\mathbb{Z}\).” (Warning 7.9)
  • ✗ Deciding \(2\equiv-2\pmod3\) because the numbers differ only by sign. ✓ Check \(n\mid(a-b)\): \(2-(-2)=4\) and \(3\nmid4\), so \(2\not\equiv-2\pmod3\). (Example 8.12)

Cases

  • ✗ Cases that miss a possibility (e.g. only \(x-a\ge0\) in an absolute-value proof). ✓ Ask: “Is every possibility in some case?” (Prop 8.20)
  • ✗ Proving “\(x\) even or \(y\) even” with cases “\(x\) even” and “\(y\) even.” That assumes the conclusion. ✓ Cases \(P\) and \(\neg P\), or go contrapositive. (Warning 8.7)
  • ✗ Thinking \(-x\) is always negative, so \(|-x|=x\). ✓ If \(x<0\), then \(-x>0\), so \(|x|=-x\) and \(|-x|=-x\ne x\). In general \(|-x|=|x|\). (Warning 8.19)
  • ✗ “The other case is similar” when it isn't. ✓ Only say WLOG when the cases really swap roles.

Contradiction & irrationality

  • ✗ For \(P\Rightarrow Q\), assuming only \(\neg Q\). ✓ Assume \(P\) and \(\neg Q\). (Advice 9.3)
  • ✗ Forgetting “in lowest terms,” so nothing is contradicted at the end. ✓ Write “\(\sqrt2=a/b\) with \(a,b\in\mathbb{N}\) in lowest terms”; the final contradiction is with that phrase.
  • ✗ Jumping from \(3\mid a^2\) to \(3\mid a\) with no reason. ✓ Cite or prove Exercise 8.5. Contrapositively: if \(a=3k+1\) or \(3k+2\), then \(a^2=3(3k^2+2k)+1\) or \(3(3k^2+4k+1)+1\), so \(3\nmid a^2\).
  • ✗ Never stating the contradiction. ✓ “…so \(1\) is even, which is false.”
  • ✗ Ignoring a hypothesis like \(x\ne0\). ✓ Note where each hypothesis is used (\(0\cdot\sqrt2\) is rational).

Sets

  • ✗ Proving only one inclusion for \(A=B\). ✓ Two labeled parts: \(A\subseteq B\), then \(B\subseteq A\). (Prop 10.7)
  • ✗ Starting from \(x\in B\) when proving \(A\subseteq B\). ✓ Start with an arbitrary \(x\in A\) and end with \(x\in B\). (§10.B)
  • ✗ Reading \(x\notin X\cup Y\) as “\(x\notin X\) or \(x\notin Y\).” ✓ It's and. (Warning 10.6)
  • ✗ Two reasons in one step when the problem asks for a single justification. ✓ Split “De Morgan and double negation” into two lines.
  • ✗ A Venn diagram as the proof. ✓ Use it to plan; chase elements to prove.

Existence & counterexamples

  • ✗ Disproving a “there exists” statement with one example. ✓ Its negation is “for all,” so give a general argument.
  • ✗ Uniqueness without existence (or the reverse). ✓ Two labeled parts.
  • ✗ Handling \(\forall a\ \exists b\) out of order. ✓ “Let \(a\)…” first, then “Fix \(b=\)…” (which may depend on \(a\)).

§6Direct proofs

Assume the premise, use definitions and algebra, reach the conclusion.

  • Even: \(n=2k\) for some \(k\in\mathbb{Z}\). Odd: \(n=2k+1\) for some \(k\in\mathbb{Z}\).
  • Trivially true: the conclusion is always true. Vacuously true: the premise is never true. (“Trivial, the \(Q\) is true. Vacuous, the premise is bogus.”)
  • Theorem / proposition / lemma / corollary: major result / basic result / helper result / quick consequence.
Let \(x\in S\). We work directly. Assume \(P(x)\). …definitions + algebra… Thus \(Q(x)\). \(\square\)
Example: if \(n\) is odd, then \(n^2-2n+3\) is even (Prop 6.18)
Let \(n\in\mathbb{Z}\). We work directly. Assume \(n\) is odd, so \(n=2k+1\) for some \(k\in\mathbb{Z}\). Then \[n^2-2n+3=(2k+1)^2-2(2k+1)+3=4k^2+2=2(2k^2+1).\] Since \(2k^2+1\in\mathbb{Z}\), \(n^2-2n+3\) is even. \(\square\)

§7Contrapositive proof

\(P\Rightarrow Q\) is equivalent to \(\neg Q\Rightarrow\neg P\), so prove whichever is easier.

  • Divides: \(a\mid b\) means \(b=ac\) for some \(c\in\mathbb{Z}\).
  • Biconditional: prove \(P\Rightarrow Q\) and \(Q\Rightarrow P\).
  • See the logic toolkit for converse / inverse / contrapositive.
Let \(x\in S\). We work contrapositively. Assume \(\neg Q(x)\). … Thus \(\neg P(x)\). \(\square\)
Example: if \(x^2-6x+7\) is odd, then \(x\) is even (Prop 7.6)
Let \(x\in\mathbb{Z}\). We work contrapositively. Assume \(x\) is odd, so \(x=2k+1\) for some \(k\in\mathbb{Z}\). Then \[x^2-6x+7=4k^2+4k+1-12k-6+7=4k^2-8k+2=2(2k^2-4k+1),\] which is even since \(2k^2-4k+1\in\mathbb{Z}\). \(\square\)

§8Proof by cases

Split into cases that cover every possibility, and prove the goal in each.

  • Same parity: both even or both odd.
  • Congruence: \(a\equiv b\pmod n\) means \(n\mid(a-b)\).
  • Absolute value: \(|a|=a\) if \(a\ge0\), and \(|a|=-a\) if \(a<0\).
  • Standard case splits: even/odd; \(3k,\,3k+1,\,3k+2\); \(x\ge0\) / \(x<0\).
  • Assuming \(P\vee Q\) gives cases \(P\) and \(Q\) (Advice 8.6). Proving \(P\vee Q\) needs cases \(P\) and \(\neg P\) (Warning 8.7).
Case 1: \(x=2k\). … Case 2: \(x=2k+1\). … In every case, [goal]. \(\square\)
Example: \(x^3\equiv x\pmod3\) (Prop 8.15)
Let \(x\in\mathbb{Z}\). By Example 8.14, \(x=3k\), \(3k+1\), or \(3k+2\) for some \(k\in\mathbb{Z}\).
Case \(x=3k\): \(x^3-x=3(9k^3-k)\).
Case \(x=3k+1\): \(x^3-x=3(9k^3+9k^2+2k)\).
Case \(x=3k+2\): \(x^3-x=3(9k^3+18k^2+11k+2)\).
So \(3\mid(x^3-x)\) in every case, i.e. \(x^3\equiv x\pmod3\) by the definition of congruence. \(\square\)

§9Proof by contradiction

Assume the statement is false and derive something impossible.

  • For \(P\Rightarrow Q\): assume \(P\) and \(\neg Q\).
  • Irrational: a real number that isn't \(a/b\) with \(a,b\in\mathbb{Z}\), \(b\ne0\).
  • Best for negative-sounding claims; if a direct proof works, prefer it.
Assume, by way of contradiction, that [negation]. … This contradicts [fact]. \(\square\)
Example: \(\sqrt2\) is irrational (Thm 9.8)
Assume, by way of contradiction, that \(\sqrt2\in\mathbb{Q}\). Write \(\sqrt2=a/b\) with \(a,b\in\mathbb{N}\) in lowest terms. Squaring and clearing denominators gives \(a^2=2b^2\), so \(a^2\) is even, hence \(a\) is even (Prop 7.16). Write \(a=2x\) with \(x\in\mathbb{Z}\). Then \(4x^2=2b^2\), so \(b^2=2x^2\) is even, hence \(b\) is even (Prop 7.16). Now \(a\) and \(b\) are both even, contradicting lowest terms. \(\square\)

§10Proofs in set theory

Prove set statements one arbitrary element at a time.

  • \(x\in A\): check every condition in \(A\)'s description.
  • \(A\subseteq B\): let \(x\in A\); show \(x\in B\).
  • \(A=B\): show \(A\subseteq B\) and \(B\subseteq A\).
  • Definitions: \(\cup\) = or, \(\cap\) = and, \(A-B\) = in \(A\) and not in \(B\), \(\bigcup_i S_i\) = in some \(S_i\), \(\bigcap_i S_i\) = in every \(S_i\), \(\overline A\) = in \(U\) and not in \(A\).
LawStatement
Commutative / associative\(A\cap B=B\cap A\); \((A\cup B)\cup C=A\cup(B\cup C)\)
Distributive\(A\cap(B\cup C)=(A\cap B)\cup(A\cap C)\); \(A\cup(B\cap C)=(A\cup B)\cap(A\cup C)\)
Identity / complement\(A\cup\varnothing=A\), \(A\cap U=A\); \(A\cup\overline A=U\), \(A\cap\overline A=\varnothing\)
De Morgan / double negation\(\overline{A\cup B}=\overline A\cap\overline B\), \(\overline{A\cap B}=\overline A\cup\overline B\); \(\overline{\overline A}=A\)
Example: \(\{x\in\mathbb{Z}:4\mid x\}\subseteq\{x\in\mathbb{Z}:2\mid x\}\) (Prop 10.3)
Let \(a\) be in the first set: \(a=4m\). Then \(a=2(2m)\), so \(2\mid a\) and \(a\) is in the second set. \(\square\)

§11Existence proofs & counterexamples

To prove “there exists,” give one; to disprove “for all,” give one that fails.

  • Constructive: “Fix \(x=\dots\).” Nonconstructive: show existence without naming it (cases, IVT).
  • Uniqueness \(\exists!\): existence, then assume two solutions and show they're equal.
To…Show…
Prove \(\forall x,\ R(x)\)General argument for arbitrary \(x\)
Prove \(\exists x,\ R(x)\)One example
Disprove \(\forall x,\ R(x)\)One counterexample
Disprove \(\exists x,\ R(x)\)General argument that \(R(x)\) always fails
Example: every odd \(n\) equals \((x+1)^2-x^2\) for exactly one \(x\in\mathbb{Z}\) (Prop 11.11)
Let \(n\) be odd, so \(n=2k+1\) for some \(k\in\mathbb{Z}\).
Existence: Fix \(x=k\). Then \((k+1)^2-k^2=2k+1=n\).
Uniqueness: Assume \(n=(x+1)^2-x^2\) and \(n=(y+1)^2-y^2\). Expanding gives \(2x+1=2y+1\), so \(x=y\). \(\square\)

Self-check flashcards

Answer in your head, then click to check.

Is “If \(x\in\mathbb{R}\) and \(x^2<0\), then \(x=5\)” trivial, vacuous, both, or neither?
Vacuous only — the premise is never true, but \(x=5\) can be false.
For \(x\in\mathbb{N}\): “if \(x\in\varnothing\), then \(x>0\).” Trivial, vacuous, both, or neither?
Both: the premise never holds and the conclusion always holds. (Example 6.15)
A proof assumes \(x\) even and \(y\) odd and shows \((x+1)y\) is odd. Which statements does it prove?
Two: “if \(x\) even and \(y\) odd, then \((x+1)y\) odd” (directly), and “if \((x+1)y\) is even, then \(x\) is odd or \(y\) is even” (contrapositively). (§7.D)
What is the contrapositive of “If \(a\mid c\) and \(b\mid d\), then \(ab\mid cd\)”?
“If \(ab\nmid cd\), then \(a\nmid c\) or \(b\nmid d\).”
Which of converse, inverse, contrapositive means the same as \(P\Rightarrow Q\)?
The contrapositive. (The converse and inverse match each other.)
“\(5x-1\) is even only if \(x\) is odd.” What do you prove?
If \(5x-1\) is even, then \(x\) is odd.
Is \(2\equiv-2\pmod3\)?
No: \(2-(-2)=4\), and \(3\nmid4\).
If \(a\equiv3\pmod5\), what is \(a^2\) mod 5?
\(a=5k+3\) for some \(k\in\mathbb{Z}\), so \(a^2=25k^2+30k+9=5(5k^2+6k+1)+4\). Thus \(5\mid(a^2-4)\), i.e. \(a^2\equiv4\pmod5\).
What can a perfect square be mod 4?
Only 0 or 1.
To prove “\(x\) even or \(y\) even,” what cases work?
“\(x\) even” (done) and “\(x\) odd” (then show \(y\) even) — or contrapositive: assume both odd.
For a contradiction proof of \(P\Rightarrow Q\), what do you assume?
\(P\) and \(\neg Q\).
Why does the \(\sqrt2\) proof need “lowest terms”?
The contradiction is that \(a\) and \(b\) are both even — impossible only if the fraction was reduced.
Is a rational times an irrational always irrational?
No: \(0\cdot\sqrt2=0\). True for a nonzero rational.
Is \(0\in\{x\in\mathbb{N}: x\text{ is a perfect square}\}\)?
No: \(0\notin\mathbb{N}\), so it fails the first condition. (§10.A)
What does \(x\notin S-T\) mean?
\(x\notin S\) or \(x\in T\).
Prove or disprove: if \(A\cup C\subseteq B\cup C\), then \(A\subseteq B\).
False: \(A=C=\{1\}\), \(B=\varnothing\).
What are \(\bigcup_{n\in\mathbb{N}}\{m\in\mathbb{Z}:m\le n\}\) and \(\bigcap_{n\in\mathbb{N}}\{m\in\mathbb{Z}:m\le n\}\)?
\(\mathbb{Z}\) and \(\{m\in\mathbb{Z}:m\le1\}\).
How do you disprove “\(\exists x\in\mathbb{R},\ x^2<-1\)”?
Show every \(x\) fails: \(x^2\ge0>-1\).
Counterexample to “if \(a\mid b\) and \(b\mid a\), then \(a=b\)”?
\(a=2,\ b=-2\).
How do you prove uniqueness?
Assume \(x\) and \(y\) both work; show \(x=y\). Prove existence separately.
“\(3n=2k\), so \(n=2(k/3)\) is even.” What's wrong?
\(k/3\in\mathbb{Z}\) is never justified. Use \(n=3n-2n=2(k-n)\).
Is \(x^2+x\) ever odd for \(x\in\mathbb{Z}\)?
Never: \(x^2+x=x(x+1)\), and one of two consecutive integers is even.
