# Book of Mormon — Chapter Categories

One category per chapter.
Doctrine: Gem · Teaching · Isaiah · Quotation · Prophecy
History: Inflection Point · Plot · Story · War · Editorial

Gem = summit chapters. Teaching = other discourse/teaching chapters.
Editorial = narrator speaking about the record. Quotation = non-Isaiah quoted texts.
