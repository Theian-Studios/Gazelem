# New Testament — Related Chapters

A selective cross-reference list for the New Testament (KJV). The Gospels include chapter-by-chapter synoptic parallels (Matthew ↔ Mark ↔ Luke covering the same events) alongside cross-book parallels drawn from all five Standard Works. Outside the Gospels, only chapters with a genuinely strong thematic, doctrinal, or narrative parallel are included. Every citation was verified directly against the project scripture text files.
